# 🍕 SliceHub

SliceHub is a modern and efficient **Pizza Ordering Mobile App** designed to offer a seamless experience for users to order their favorite pizzas from local restaurants. The app also includes a powerful **Admin Dashboard** for managing orders, pizza menu, sending notifications, and monitoring the system in real-time.

---

## 🚀 Project Features

### ✅ User Side:
- Browse pizza menu with images, descriptions, and prices.
- Add multiple pizzas to cart and place orders easily.
- Track order status in real-time.
- Receive instant push notifications (order updates, offers, promotions).
- Clean and user-friendly interface for a smooth experience.

### ✅ Admin Side:
- Manage pizza items: add, update, delete items.
- View and manage all user orders.
- Send remote push notifications to users.
- Monitor active orders and system usage in real-time.

---

## ⚡ Tech Stack

- 📱 Frontend (Mobile App): React Native , Expo
- 🖥️ Admin Dashboard: React.js , Typescript
- 💾 Backend & Database: Supabase 
- 🔔 Notifications: Expo Notification 
- 🔐 Authentication: JWT / OAuth

---

## 🎯 Project Objective

SliceHub demonstrates a full-stack solution covering:
- Mobile app development (React Native)
- Backend API design and implementation
- Real-time push notifications
- Admin panel for system management
- Best coding practices and clean project structure
